<h3 align="center">Всё ваше бесплатное облачное хранилище — один диск.</h3>

> 🌍 [English](../README.md) · Русский

Google 15 ГБ, OneDrive 5 ГБ, pCloud 10 ГБ… у вас уже есть **более 100 ГБ бесплатно**, разбросанных по шести приложениям — у каждого свой вход, своя кнопка загрузки и свой поиск.

**PleumCloud превращает это в один диск.** Подключите аккаунты один раз — и просматривайте, ищите, загружайте и перемещайте файлы, как будто они живут на одном диске; каждый файл несёт значок, показывающий, в каком облаке он находится.

> Родился в августе 2026 года, на неделе, когда Naver наконец открыл
> [MyBox Open API](https://developers.mybox.naver.com) после 13 лет.

## ✨ Возможности

- 🔗 **Подключение в один клик** — официальный OAuth (Google, OneDrive, Dropbox, pCloud); токены доступа (MyBox, Drime, Koofr); WebDAV для остальных. Учётные данные хранятся в системном брелоке
- 🗂️ **Единый диск** — общий вид со значками облаков + живая панель занятого места
- 🔍 **Глобальный поиск** — одно нажатие ищет по всем подключённым аккаунтам
- 🧠 **Умное размещение** — загрузки уходят в облако с максимумом свободного места; правила настраиваются
- 🚚 **Межоблачные передачи** — фоновые задачи, которые продолжаются при закрытой вкладке
- 🖥️ **Локальный приоритет** — один бинарник (~18 МБ) со встроенным интерфейсом, без сервера
- 🧩 **17 провайдеров** — 9 нативных коннекторов + 8 через мост rclone

## Установка (macOS / Linux)

```bash
curl -fsSL https://raw.githubusercontent.com/gachon-star-want/pleumcloud/main/scripts/install.sh | bash
```

Запустите `pleumcloud` — браузер откроет `http://localhost:7777`.
