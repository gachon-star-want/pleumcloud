<h3 align="center">Semua penyimpanan awan gratismu, dalam satu drive.</h3>

> 🌍 [English](../README.md) · Indonesia

Google 15GB, OneDrive 5GB, pCloud 10GB… kamu sudah punya **lebih dari 100GB gratis** yang tersebar di enam aplikasi — masing-masing dengan login, tombol unggah, dan pencariannya sendiri.

**PleumCloud mengubah semuanya menjadi satu drive.** Hubungkan akunmu sekali, lalu jelajahi, cari, unggah, dan pindahkan file seolah semuanya ada di satu disk — setiap file membawa lencana yang menunjukkan di awan mana ia berada.

> Lahir pada Agustus 2026, di minggu saat Naver akhirnya membuka
> [MyBox Open API](https://developers.mybox.naver.com) setelah 13 tahun.

## ✨ Fitur

- 🔗 **Sambung sekali klik** — OAuth resmi (Google, OneDrive, Dropbox, pCloud); token akses (MyBox, Drime, Koofr); WebDAV untuk lainnya. Kredensial tersimpan di keychain OS
- 🗂️ **Satu drive terpadu** — tampilan tunggal dengan lencana per awan + dasbor kapasitas langsung
- 🔍 **Pencarian global** — sekali ketik, mencari di semua akun yang tersambung
- 🧠 **Penempatan cerdas** — unggahan otomatis pergi ke awan dengan ruang kosong terbanyak; aturan bisa diatur
- 🚚 **Transfer antar-awan** — tugas latar belakang yang tetap jalan walau tab ditutup
- 🖥️ **Local-first** — satu biner (~18MB) dengan UI tersemat, tanpa server
- 🧩 **17 penyedia** — 9 konektor native + 8 lewat jembatan rclone

## Instalasi (macOS / Linux)

```bash
curl -fsSL https://pleumcloud.dev/install.sh | bash
```

Jalankan `pleumcloud` — browser akan terbuka di `http://localhost:7777`.
