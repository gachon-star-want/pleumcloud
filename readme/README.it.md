<h3 align="center">Tutto il tuo spazio cloud gratuito, un solo disco.</h3>

> 🌍 [English](../README.md) · Italiano

Google 15 GB, OneDrive 5 GB, pCloud 10 GB… hai già **più di 100 GB gratuiti** sparsi su sei app, ognuna con il suo login, il suo pulsante di caricamento e la sua ricerca.

**PleumCloud li trasforma in un unico disco.** Connetti gli account una volta, poi sfoglia, cerca, carica e sposta file come se vivessero su un'unica unità — ogni file porta un badge che indica in quale cloud si trova.

> Nato nell'agosto 2026, la settimana in cui Naver ha finalmente aperto la
> [MyBox Open API](https://developers.mybox.naver.com) dopo 13 anni.

## ✨ Caratteristiche

- 🔗 **Connessione con un clic** — OAuth ufficiale (Google, OneDrive, Dropbox, pCloud); token d'accesso (MyBox, Drime, Koofr); WebDAV per il resto. Le credenziali restano nel portachiavi di sistema
- 🗂️ **Un disco unificato** — vista unica con badge per cloud + dashboard capacità in tempo reale
- 🔍 **Ricerca globale** — un battito cerca in tutti gli account collegati
- 🧠 **Posizionamento intelligente** — gli upload vanno nel cloud con più spazio libero; regole configurabili
- 🚚 **Traferimenti tra cloud** — processi in background che continuano a scheda chiusa
- 🖥️ **Local-first** — un unico binario (~18 MB) con interfaccia incorporata, senza server
- 🧩 **17 provider** — 9 connettori nativi + 8 tramite il bridge rclone

## Installazione (macOS / Linux)

```bash
curl -fsSL https://pleumcloud.dev/install.sh | bash
```

Esegui `pleumcloud` — il browser si apre su `http://localhost:7777`.
