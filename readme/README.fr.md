<h3 align="center">Tout votre stockage cloud gratuit, un seul disque.</h3>

> 🌍 [English](../README.md) · Français

Google 15 Go, OneDrive 5 Go, pCloud 10 Go… vous avez déjà **plus de 100 Go gratuits** éparpillés sur six applications, chacune avec sa connexion, son bouton d'envoi et sa propre recherche.

**PleumCloud transforme cet ensemble en un seul disque.** Connectez vos comptes une fois, puis parcourez, cherchez, envoyez et déplacez vos fichiers comme s'ils vivaient sur une seule unité — chaque fichier porte un badge indiquant dans quel cloud il se trouve.

> Né en août 2026, la semaine où Naver a enfin ouvert l'
> [API MyBox](https://developers.mybox.naver.com) après 13 ans.

## ✨ Fonctionnalités

- 🔗 **Connexion en un clic** — OAuth officiel (Google, OneDrive, Dropbox, pCloud); jetons d'accès (MyBox, Drime, Koofr); WebDAV pour le reste. Les identifiants restent dans le trousseau système
- 🗂️ **Un disque unifié** — vue unique avec badges par cloud + tableau de bord des capacités en direct
- 🔍 **Recherche globale** — une frappe cherche dans tous les comptes connectés
- 🧠 **Placement intelligent** — les envois partent vers le cloud le plus disponible; règles configurables
- 🚚 **Transferts inter-clouds** — des tâches de fond qui continuent même onglet fermé
- 🖥️ **Local d'abord** — un seul binaire (~18 Mo) avec l'interface intégrée, sans serveur
- 🧩 **17 fournisseurs** — 9 connecteurs natifs + 8 via le pont rclone

## Installation (macOS / Linux)

```bash
curl -fsSL https://raw.githubusercontent.com/gachon-star-want/pleumcloud/main/scripts/install.sh | bash
```

Lancez `pleumcloud` — votre navigateur s'ouvre sur `http://localhost:7777`.
