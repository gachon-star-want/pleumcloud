PleumCloud — Privacy Policy

PleumCloud is local-first software. This policy describes what the application running on your machine does with data.

What we collect

Nothing. PleumCloud runs on your computer and has no telemetry, analytics, crash reporting or accounts of its own. The developers of PleumCloud never see your files, credentials, or usage.

What is stored on your machine

  • Cloud account tokens — in your OS keychain (macOS Keychain, Windows Credential Manager, libsecret on Linux; a permission-restricted file on headless systems).
  • A file index (names, sizes, modification dates) in a local SQLite database under ~/.pleumcloud/ so browsing and search work instantly.

What leaves your machine

Only traffic that is required to operate the cloud accounts you connect: authentication, file listings, and file transfers between your machine and those providers (or between providers, when you request a cross-cloud transfer). Each provider's own privacy policy applies to data they store.

OAuth permissions

When you connect a cloud, its provider shows exactly which permissions are requested (for example, Google's Drive scope). PleumCloud requests the minimum needed to list, transfer and manage the files you direct it to, and never requests credentials for other services.

Self-hosted server mode

If you run PleumCloud in server mode for multiple users, you are the data controller: the same local-storage guarantees apply on that server, and no data is forwarded anywhere else.

Contact

Open an issue at the project repository for any privacy question.
